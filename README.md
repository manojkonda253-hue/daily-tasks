1. To-Do List Manager

Problem Statement:
Many people find it difficult to organize their daily tasks efficiently, leading to missed deadlines and reduced productivity. Existing task management applications are often too complex for users who only need a simple solution. Develop a responsive To-Do List application that allows users to create, update, delete, and mark tasks as completed while storing data locally in the browser.

Objectives:
• Add new tasks
• Edit existing tasks
• Delete tasks
• Mark tasks as completed
• Filter tasks (All, Active, Completed)
• Store tasks using Local Storage
